# DC01 installation

DC01 hosts Active Directory Domain Services and DNS for `corp.test`. Windows Server 2025 is installed with Desktop Experience on QEMU/KVM.

## Install Windows Server

1. Create a VM named `DC01` in virt-manager using local installation media.
2. Select the Windows Server 2025 Evaluation ISO.
3. Connect the network adapter to the isolated `corp-lab` network.
4. Install Windows Server 2025 Standard Evaluation with Desktop Experience.
5. Set the local Administrator password and sign in.

## Set the hostname

The libvirt VM name and Windows hostname are configured separately. Run PowerShell as Administrator to check the Windows hostname:

```powershell
hostname
```

If the hostname differs from `DC01`, rename the computer and restart:

```powershell
Rename-Computer -NewName "DC01" -Restart
```

After restarting, sign in and verify the hostname and network adapter:

```powershell
hostname
Get-NetAdapter
```

Continue with [static IP and DNS configuration](../windows-networking/README.md) before installing Active Directory.
