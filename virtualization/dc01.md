# DC01 Kurulumu

DC01, `corp.test` için AD DS ve DNS hizmetlerini sağlar. QEMU/KVM üzerinde Windows Server 2025 Standard Evaluation, Desktop Experience kullanır.

## Yapılandırma

| Bileşen | Yapılandırma |
|---|---|
| VM adı ve bilgisayar adı | `DC01` |
| İşletim sistemi | Windows Server 2025 Standard Evaluation, Desktop Experience |
| Ağ | `corp-lab` |
| Sunucu rolleri | AD DS ve DNS |

## Bilgisayar Adı

`Rename-Computer`, bilgisayar adını `DC01` olarak ayarlar ve Windows'u yeniden başlatır. Komut, AD DS kurulumu öncesinde yönetici yetkisiyle çalıştırılır.

```powershell
Rename-Computer -NewName "DC01" -Restart
```

Bilgisayar adı ve ağ adaptörü sorguları:

```powershell
hostname
Get-NetAdapter
```
