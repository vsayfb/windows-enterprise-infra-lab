# DC01 installation

DC01 hosts Active Directory Domain Services and DNS for `corp.test`. Windows Server 2025 is installed with Desktop Experience on QEMU/KVM.

## Configuration

| Component | Configuration |
|---|---|
| VM name and guest hostname | `DC01` |
| Operating system | Windows Server 2025 Standard Evaluation, Desktop Experience |
| Network | `corp-lab` |
| Server roles | AD DS and DNS |

## Guest hostname

The guest hostname is set before AD DS promotion. `Rename-Computer` requires elevation and restarts Windows.

```powershell
Rename-Computer -NewName "DC01" -Restart
```

Hostname and adapter queries:

```powershell
hostname
Get-NetAdapter
```

Networking configuration: [DC01 static IP and DNS](../windows-networking/README.md).
